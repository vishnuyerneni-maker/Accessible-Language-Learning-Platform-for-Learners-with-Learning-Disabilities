🔌 API Reference

Base URL: http://localhost:5002/api | All protected routes require Authorization: Bearer <token>

Authentication (/api/auth)

POST/api/auth/registerPublic
Register a new user. Body: { username, email, password, role?, name? } → Returns user object + JWT token.
POST/api/auth/loginPublic
Login with credentials. Body: { username, password } → Returns user + token, or mfaRequired: true if MFA enabled.
POST/api/auth/login-mfaPublic
Complete MFA login. Body: { userId, code } → Returns user + token after verifying TOTP code.
GET/api/auth/profileAuth Required
Get current user's profile (decoded from JWT). Returns full user object without password.
POST/api/auth/mfa/generate-publicPublic
Generate a public MFA secret during registration. Body: { username } → Returns { secret, qr_code }.
POST/api/auth/mfa/generateAuth Required
Generate MFA secret for authenticated user. Returns { secret, qr_code }.
POST/api/auth/mfa/verifyAuth Required
Verify a TOTP code. Body: { code, secret } → Returns { verified: true/false }.
POST/api/auth/mfa/enableAuth Required
Enable MFA for the user. Body: { secret, code } → Stores MFA secret and enables MFA.
POST/api/auth/mfa/disableAuth Required
Disable MFA for the user. Removes MFA secret and sets mfaEnabled: false.

Users (/api/users)

GET/api/usersAdmin/Teacher
Get all users. Returns array of user objects (without passwords).
DELETE/api/users/:idAdmin/Teacher
Delete a user by MongoDB _id.
PUT/api/users/progressAuth Required
Update course progress. Body: { courseId, percent } → Awards XP, checks badges, returns gamification data.
GET/api/users/child/:idAuth Required
Get linked children's progress (parent only). Returns array of child user profiles.
PUT/api/users/child/lockAuth Required
Toggle course lock for a child. Body: { childId, courseId } → Returns updated parentSettings.
GET/api/users/statsAuth Required
Get system statistics: totalUsers, totalCourses, activeStudents, totalXP, avgProgress, completionRates.

Courses (/api/courses)

GET/api/coursesAuth Required
Get all courses. Supports query params for filtering by category.
POST/api/coursesAdmin/Teacher
Create a new course. Body: { id, title, description, totalModules, image, category }.
PUT/api/courses/:idAdmin/Teacher
Update a course by _id or custom id. Body: partial course object.
DELETE/api/courses/:idAdmin/Teacher
Delete a course by _id or custom id.

Forum (/api/forum)

GET/api/forumAuth Required
Get all forum posts sorted by newest first. Returns array with embedded replies.
POST/api/forumAuth Required
Create a forum post. Body: { title, content, tags? }.
POST/api/forum/:id/replyAuth Required
Add a reply to a forum post. Body: { content }.

Announcements (/api/announcements)

GET/api/announcementsAuth Required
Get all active announcements sorted by newest first.
POST/api/announcementsAdmin Only
Create an announcement. Body: { text }.
DELETE/api/announcements/:idAdmin Only
Delete a single announcement by _id.
DELETE/api/announcementsAdmin Only
Clear all announcements.

👤 User Guide

Roles Overview

SpeakSmart supports 4 user roles, each with distinct capabilities:

RoleDashboardKey Capabilities
StudentStudent DashboardView courses, take quizzes, speech practice, NLP writing lab, AI assistant, track XP/badges/streaks, forum
TeacherTeacher DashboardView analytics, manage courses (CRUD), view student progress, push announcements, manage users
AdminAdmin DashboardFull system control: manage all users, create/delete courses, push announcements, view system stats
GuardianGuardian DashboardMonitor child progress, lock/unlock courses, view activity reports, manage linked children

Student Features

  • Course Library — Browse courses with categories (General, Dyslexia, Speech). Start courses, view progress.
  • Lesson Player — Interactive lessons with concept cards, slide navigation, text-to-speech read-aloud.
  • Quiz System — Multiple choice, written AI-evalulated, and voice pronunciation questions.
  • Speech Practice Lab — Record your pronunciation, get word-by-word accuracy with Levenshtein scoring.
  • NLP Writing Lab — AI-powered writing exercises with grammar and content evaluation.
  • AI Writing Assistant — Real-time AI tutoring and writing feedback.
  • Gamification — Earn XP, level up (8 levels), collect 8 badges, maintain daily streaks.
  • Discussion Forum — Create posts, add replies, tag discussions.
  • Multi-Factor Auth (MFA) — Enable TOTP-based MFA from your profile for enhanced security.
  • Hindi Language Support — Toggle between English and Hindi for full bilingual UX.

Setup Instructions

# 1. Clone & install
git clone <repo-url>
cd react-app
npm install
cd backend && npm install && cd ..

# 2. Create backend/.env
MONGO_URI=mongodb+srv://...
JWT_SECRET=your_jwt_secret
PORT=5002

# 3. Seed the database
cd backend && node seed.js && cd ..

# 4. Run development servers
# Terminal 1: Backend
cd backend && node server.js
# Terminal 2: Frontend
npm run dev
